Automated BLE security validation framework

Texas Instruments, 2024–2025. Python, pytest, Jenkins, Groovy, TI UniFlash

TI's Bluetooth Low Energy devices have to be checked against SweynTooth, a published set of BLE vulnerabilities that can make devices crash or misbehave. Running those checks by hand for every SDK and firmware version was hard to repeat reliably. I designed and built the system that runs them end to end on real hardware.

  1. Prepare firmware
  2. Flash devices
  3. Configure environment
  4. Run security tests
  5. Collect logs
  6. Evaluate pass/fail

Each run is triggered and reported through Jenkins.

  • Wrote the Python and pytest orchestration that flashes boards, runs the tests, captures device responses and produces pass/fail results
  • Built the Jenkins pipelines in Groovy so validation runs automatically on Windows test agents
  • Mapped known vulnerabilities to the SDK versions they affect, and debugged problems spanning software, firmware, hardware and test infrastructure
  • Hardware: TI CC2640R2 and CC2340R5, Nordic nRF52840

I presented the framework to engineering teams and management, and R&D adopted it for pre-release validation. The code is proprietary to TI.
