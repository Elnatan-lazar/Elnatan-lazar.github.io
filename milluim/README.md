# המילואים נגמרים עוד… ❤

אתר ספירה לאחור לסיום המילואים, עם שעון חול שכל גרגר חול שלו הופך ללב אדום,
וחמש סצנות פיקסל־ארט מונפשות שרצות בלולאה.

**כתובת:** https://elnatan-lazar.github.io/milluim/

## איך משנים את תאריך השחרור

פותחים את `script.js`, ובראש הקובץ יש בלוק `CONFIG`:

```js
const CONFIG = {
  endDate:   new Date(2026, 8, 24, 15, 30, 0),  // (שנה, חודש־1, יום, שעה, דקה)
  startDate: null,                              // ברירת מחדל: שבוע לפני הסיום
};
```

* `endDate` — מתי המילואים נגמרים. שימו לב: **החודש מתחיל מ־0** (0 = ינואר, 8 = ספטמבר).
* `startDate` — מתי המילואים התחילו. קובע כמה חול יש בשעון בתחילת הספירה.
  אם משאירים `null`, מניחים שבוע אחורה.

השעה נמדדת לפי השעון המקומי של המכשיר שפותחים בו את האתר.

הדמויות "מדברות" בבועות אימוג'י, ואפשר לדלג קדימה/אחורה עם הכפתורים
או בלחיצה על התמונה.

**שעון החול:** כשהוא מתמלא בלבבות — כולם עפים למעלה והספירה מתחילה סיבוב חדש.
המונה שמתחת סופר את כל הלבבות שנאספו מאז שפתחתם את הדף.

## מבנה

| קובץ | תוכן |
|------|------|
| `index.html` | מבנה הדף (עברית, RTL) |
| `style.css`  | עיצוב רספונסיבי (מובייל ודסקטופ) |
| `script.js`  | הספירה לאחור, שעון החול והסצנות — הכול מצויר על `<canvas>` בפיקסלים |
